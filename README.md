# COD Player

App nghe nhạc Android giao diện HUD siêu anh hùng.

- **Thư viện kiểu Winamp**: danh sách đánh số, tách riêng FLAC / WAV / MP3 / khác, xem theo thư mục, tìm kiếm, sắp xếp
- **Chỉnh âm như Poweramp**: EQ 10 băng có đường cong đáp tuyến, 16 preset (có Bolero, Rock Ballad…), lưu preset riêng, Preamp, Bass, Treble, độ rộng stereo, cân bằng trái/phải, chống vỡ tiếng
- **Hiệu ứng hình ảnh**: Lõi năng lượng, Cột phổ cổ điển, Phổ gương, Sóng âm — không cần quyền micro
- Hiện thông số bài: bit, kHz, kbps, nhãn HI-RES
- Phát nền, điều khiển trên thông báo/màn hình khoá, hẹn giờ tắt, 6 bộ màu giao diện

Tải APK mới nhất: nhánh `apk` hoặc mục Releases.
